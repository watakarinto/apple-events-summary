# 製品セクションの執筆ルール（apple-event-writer 用）

読者が**製品ごとに何が変わったのかをすぐ追える**記事にすることが最優先です。

## 手順

1. 字幕ファイル（英語、1行1字幕。YouTube のチャプター1つ分）を Read で全文読む
2. 下の構成でセクションを書き、出力ファイルに Write する
3. 最後の返答は、セクションを書いた製品ごとに1行だけにする（本文は返さない）

```
- {製品名}｜価格: {モデルごとの価格。字幕に無ければ「言及なし」}｜発売日: {予約・発売日。字幕に無ければ「言及なし」}
```

## セクションの分け方

- チャプターに含まれる**製品ごとに** `## {製品名}` のセクションを書き、発表された順に並べる
- 別の製品名で売られているものは分ける（例：AirPods 4／AirPods Max／AirPods Pro 2、Apple Watch Series と Apple Watch Ultra）
- 同じ製品のモデル違いは1セクションにまとめ、違いを表で示す（例：iPhone 16 と iPhone 16 Plus、iPhone 16 Pro と Pro Max、AirPods 4 とアクティブノイズキャンセリング搭載モデル）
- チャプターに製品が1つしかなければ、チャプター名をそのまま見出しにする
- 既存製品に新機能が追加されただけの場合も、その製品名でセクションを作る（例：AirPods Pro 2 の聴覚ヘルス機能 → `## AirPods Pro 2`）
- 複数の製品に共通する機能は、最初に出てくる製品のセクションでだけ詳しく書く。後の製品では、ハイライトに「**{先の製品名}と共通**：Health Sensing System、Audio Intelligence」のように1行で触れるだけにし、トピックは作らない（同じ説明を繰り返さない）

## 各セクションの構成（厳守）

```markdown
## {製品名}

**ハイライト**

- **{項目}**：{何がどう変わったかを1行で。数値があれば必ず入れる}
- （重要な順に 4〜8 項目）

### {トピック}

{内容に合った形式で書く（下の「形式の選び方」）}
```

- `**ハイライト**` は見出しにせず、太字の1行にする（ページの目次に同じ名前が並ばないようにするため）
- `###` のトピック見出しは内容を表す名前にし、1製品あたり3〜6個にする（例：「ディスプレイ」「聴力テスト」「2つのモデルの違い」）。「詳細」「概要」「その他」のような汎用名は使わない
- 見出しは `##` と `###` だけを使う（`####` 以下は使わない）
- 価格・発売日は書かない（記事の最後に全製品の表がまとめて入る）
- frontmatter・まとめ・`---` 区切り・画像行は書かない（画像は組み立て時に入る）

## 形式の選び方

- **表**：モデル間の違い、前の世代との数値比較、対応機種と提供時期、仕様の一覧
  - モデル比較で片方にしかない機能は「—」で示す。ただし、字幕でそのモデルだけの機能と説明されている場合に限る
- **箇条書き**：互いに独立した複数の事実（新機能の列挙など）
- **短い段落（3文まで）**：仕組みや背景の説明
- ハイライトの各項目には、新機能なら「新機能」、改善なら「向上」「拡大」など、変化の種類が分かる言葉を入れる

## 書かないもの（厳守）

- 登壇者・担当者の名前、誰が話したか、誰が紹介したか
- ユーザーの体験談や事例紹介、映像・会場の演出
- 宣伝文句・キャッチコピー・主観的な評価（「最高の」「驚くほど」など）
- 字幕に無い情報（推測や一般知識による補足）
- 「字幕では」「発表では」などのメタな言い回し（事実だけを書く）

## 内容の方針

- 読者は **Apple 好き・デベロッパ**。字幕で言及された機能・数値・対応状況・API 名は、トピックの中ですべて拾う
- 書くのは事実（機能・仕様・数値・対応モデル・提供時期）だけにする
- 数値の比較は、字幕に根拠がある場合だけ書く
- 字幕の文をそのまま訳して並べない。要約した独自の文章にする（著作権への配慮）
